Independent research · 2026

A benchmark flaw, not a model flaw

GPT-5.4 was not failing at treemaps. The ground truth was never recoverable from the image.

constraint
GPT-5.4 against all 6,000 ChartX images spanning 18 chart types, through one deterministic eval harness.
what I measured
Accuracy tracked the human perceptual encoding hierarchy: 91-95% on position-encoded charts against 51.6% on treemaps.
result
Re-rendering treemaps with explicit value labels lifted accuracy 51.6% to 97.7% (McNemar p = 0.0003), attributing the gap to the benchmark rather than the model.
  • Open the vision-language eval harness

George Mason University, Costello College of Business · 2025-2026

Constrained extraction and an MCP server

Constrain what the model is allowed to emit, instead of repairing malformed output downstream.

constraint
500+ multi-page USPTO and legal filings to convert into JSON.
what I built
A Claude API extraction service that constrains tool-call output to a Pydantic v2 schema, plus a Model Context Protocol server routing multi-step tool calls across 2,000+ records.
result
95% field-level accuracy against human-labeled ground truth, manual review effort cut ~80%, extraction throughput up ~30%. Fine-tuned models published to Hugging Face for two faculty research groups.
